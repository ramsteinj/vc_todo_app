# 03. 기술 스택

## Frontend

### Vue.js 3
컴포넌트 기반 Web UI 프레임워크.

### Vite
Frontend 개발 서버 및 빌드 도구.

### HTML5
Web Application의 기본 마크업.

### Bootstrap v5.0
화면 스타일과 Responsive Layout 구현.

### JavaScript
Frontend 애플리케이션 로직 구현.

## Backend

### Python 3
Backend 프로그래밍 언어.

### Django
Web Framework 및 ORM 제공.

### Django REST Framework
REST API, Serializer, Validation 등을 구현하기 위한 Django 기반 도구.

## Database

### PostgreSQL
애플리케이션의 영구 데이터 저장소.

## 개발 도구

- Git
- OpenCode
- GLM-5.3 Flash

## 기술 선택 원칙

요구사항에 필요하거나 명시적으로 승인되지 않은 새로운 Framework, Database, State Management Library, UI Framework 또는 주요 Infrastructure를 임의로 추가하지 않는다.

가능하면 새로운 의존성을 추가하기 전에 기존 Framework가 제공하는 기능을 우선 사용한다.
